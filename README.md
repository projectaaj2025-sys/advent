# Теплее — зимний адвент

Самостоятельный русскоязычный адвент с 31 заданием и отдельным конструктором на 1–31 день. **Не является копией portfolio.davplayground.com/advent/: исходный сайт был недоступен в среде разработки, его дизайн, файлы и задания не перенесены.** Получен сохранённый HTML оригинала, но без папки `_files` с CSS, JavaScript и изображениями. Для точного переноса требуется полный архив с этими ресурсами.

## Запуск

```sh
npm install
npm run dev
```

`npm run build` — production-сборка в `dist/`. `npm test` — тесты данных и валидации импорта. Можно разместить `dist/` на статическом хостинге, включая подкаталог при настройке Vite `base`.

## Возможности

- Отдельный встроенный адвент: редактор его не меняет.
- Просмотр всех заданий, отметки выполнения, фильтр невыполненных дней.
- Свой календарь: название, описание, количество дней, символы и задания.
- Сохранение календаря и прогресса в localStorage. Черновик сохраняется только кнопкой «Сохранить адвент»; при закрытии несохранённые изменения теряются.
- Экспорт и импорт JSON с проверкой структуры и ограничением размера файла.
- «Поделиться» в своём календаре и конструкторе: сжатый снимок календаря в URL-фрагменте, без сервера и аккаунта. Получатель видит вкладку «По ссылке»; его календарь не перезаписывается. Копию можно открыть в конструкторе и явно сохранить. Прогресс разных полученных календарей разделён.
- Год в интерфейсе не отображается.
- Адаптивная вёрстка, поддержка клавиатурного фокуса и reduced motion.

Бэкенда, аккаунтов и синхронизации нет. Очистка данных браузера удаляет сохранённое; для резервной копии используйте экспорт JSON. Для передачи нажмите «Поделиться» и скопируйте ссылку. Ссылка открывается на том же хосте, где создана: для постоянного использования разместите сайт на постоянном публичном адресе. Она содержит задания, доступные любому обладателю ссылки, но не прогресс. Уже отправленные ссылки не обновляются при редактировании. Сжатый фрагмент ограничен 16 000 символов; длинные ссылки могут обрезаться мессенджерами, в таком случае используйте JSON. Данные находятся в URL-фрагменте и приложением не отправляются на сервер.

## Публикация на GitHub Pages

Pages уже настроен на корень `main`. Исходный HTML находится в `site/index.html`, а корневой `index.html` и `assets/` — готовая статическая версия. После изменения исходников выполните `npm run build:publish` и включите обновлённые корневые файлы в PR. CI проверяет соответствие опубликованных файлов исходникам. Pages публикует их после слияния в `main`; права на изменение настроек Pages не нужны.
